# Macro-training
# Макроэкономический анализ (R)

Аналитический проект на R: сравнение макроиндикаторов стран, прогноз
роста ВВП (ARIMA) и анализ реакции экономики на шок процентной ставки (VAR).

**Отчёт:** https://ВАШ-ЛОГИН.github.io/macro-analysis-r/macro_analysis.html

## Данные
- World Bank WDI: рост ВВП, инфляция, безработица, счёт текущих операций
- FRED: промпроизводство, ИПЦ, безработица, ставка ФРС (США, месячные)

## Методы
ADF/KPSS, ARIMA с проверкой на отложенной выборке, VAR, функции
импульсного отклика, разложение дисперсии.

## Главный вывод
[1–2 предложения по итогам вашего анализа]

## Как воспроизвести
Откройте `macro_analysis.Rmd` в RStudio и нажмите Knit.
Нужны R ≥ 4.1 и интернет; пакеты устанавливаются автоматически.
